Quantitative Risk Scoring Model

The triage engine computes incident severity deterministically:

  • Asset Tier ($W_A$, max 40): Tier-0 Domain Controller = 40, ERP/CRM = 25, Workstation = 12, Staging = 5.
  • Attack Vector ($W_V$, max 35): Ransomware = 35, BEC / AiTM = 30, VPN = 28, DDoS = 18, Insider = 15.
  • Financial Exposure ($W_E$, max 20): > $1M = 20, > $500k = 14, > $100k = 8, < $100k = 2.
  • Blast Radius ($W_B$, max 10): $Systems \times 2$ (capped at 10).
  • Thresholds: ≥ 80: SEV-1 Critical (<15m SLA), 55-79: SEV-2 High (<30m), 30-54: SEV-3 Medium (<2h), < 30: SEV-4 Low (<8h).
